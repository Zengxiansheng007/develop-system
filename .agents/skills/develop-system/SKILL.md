# Develop System

从 Matt Pocock 的 ask-matt 改造，原始快照与许可见 [source.json](source.json)。

`develop-system 分派 → 专业技能执行并判断本帧完成 → develop-system 登记回流 → 恢复父技能 / 下一技能 / 等待 / 关闭流程`

## 双入口

- `/develop-system` 或 `$develop-system` 显式启动/恢复受管流程，在当前会话衔接已授权的工作。每个目标保存独立状态，不后台唤醒。
- `/ask-matt` 或 `$ask-matt` 是独立纯导航入口，使用 [导航地图](references/navigation.md) 给出建议，不分派、不写执行状态，也不推进已有流程。
- 流程外的独立技能调用按自身约定返回调用方；安装或隐式加载技能不构成启动流程。

## 调度职责

本技能选择路线、传递上下文、创建执行帧、管理依赖和状态、接收结果以及报告进度。只检查结果的归属、结构、版本、证据文件新鲜度和依赖，不判断代码正确性或需求是否实现。

**专业工作交由所选技能执行：本技能不写业务代码、编写/运行测试、集成代码、评审代码或生成业务验收结论。**同一代理顺序执行时先读取真实技能并切换到专业执行帧；专业工作完成后返回调度角色。角色切换不等于子代理或独立评审代理。

职责与按需路线详见 [职责与路线](references/responsibilities.md)。缺失技能进入阻塞，不由调度器内置代做。`completion_checked` 和 `acceptance_checks` 由执行技能产生；人工验收由用户真实确认。调度器只能引用已回流结论关闭运行。

## 进入与恢复

1. 读取当前项目 AGENTS.md、目标、范围与已有产物；当前指令优先于旧笔记。验收条件从用户目标或规格提取，语义不明确时分派需求技能。
2. 读取 [registry.json](registry.json) 与 [统一执行协议](references/codex-runtime.md)，按任务裁剪计划。已有有效规格、测试或评审结果可复用，来源及版本须保留。
3. 使用 [状态工具](references/state-operations.md) 创建/恢复目标项目独立 run。旧 schema v1/v2 不自动续跑；当前 v3 只登记专业技能来源的结论。
   直接 grill、受管访谈或恢复访谈时，先读取 [grill 入口与回流操作](references/grill-routing.md)，通过只读判定确认归属，不使用历史最新运行猜测。
4. 解析实际技能路径并读取正文，记录文件 hash。用户路径和会话目录优先；目录未列出时按项目 .agents/skills、.codex/skills、用户 .agents/skills、.codex/skills 查找。同名只选一个版本。
5. 分派最早就绪且必要的工作。模板是可裁剪路线，不是每个任务都必须执行全部技能。

## 调度闭环

1. **选择**：依据当前输入、依赖、阻塞和专业技能返回结论选择下一技能；无法判断专业问题时分派该领域技能。
2. **分派**：传入目标、范围、绝对项目目录、输入/规格、验收项编号、授权、职责与 `return_to: develop-system`，登记帧。
3. **让出执行**：实际工作按所选技能进行。辅助请求也经本技能登记子帧；真实委派由总路由统一调用，授权/工具/隔离条件不足时切换专业角色顺序执行。
4. **登记回流**：成功、失败、等待、跳过、取消均先回流。核对运行/帧/输入版本与 [机器检查记录](references/check-records.md)，去重并保存专业结果；辅助回流后恢复父技能，父任务未结束不能推进主阶段。
5. **处理缺口**：按明确返回的发现分派修复、设计或复核技能。发现关闭引用专业技能的 `resolved_findings` 结论，不由调度器自行验证修复。
6. **衔接**：下一必要任务就绪且已授权时说明路由原因后同轮继续。根 grill-with-docs 完成回流后，按 [职责与路线](references/responsibilities.md) 自动选择 `to-spec → to-tickets` 或 `implement`，不请求路线审批。验收不足则分派对应验证/评审技能；真实人工结果缺失则等待。

授权开发不自动包含部署、发布或外部消息。真实用户决定、人工操作和范围外动作遵守各自授权边界，不重复询问已授权的常规阶段切换。

## 关闭与异常

- 所有必要步骤/子帧/发现满足，且每项验收都有当前版本的专业技能或用户结论时，登记 completed 并汇总来源；这是行政性关闭，不是本技能重新验收。
- 技能缺失准确记录 blocked；可继续独立工作，但不得声称调用了未安装技能。未来能力通过 [扩展接口](references/extensions.md) 接入，临时能力仅保存当前运行。
- 同技能、同输入、同阻塞两次无新证据时停止重复，报告需要的信息或环境变化。
- 输入、代码、测试或评审证据发生变化，按依赖失效规则重新分派对应专业技能；哈希一致不证明运行环境健康。
- 真实阻塞/人工等待保存 blocked/waiting_user；仅用户明确暂停/取消时记 paused/cancelled。等待时间不是答复。

本技能是代理遵守的调度协议及状态工具，不注册系统完成钩子；会话结束后依靠显式恢复继续。
